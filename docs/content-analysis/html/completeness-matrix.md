# ZE-WebLab – HTML-Vollständigkeits-Matrix

## Zweck

Diese Matrix dient der systematischen Prüfung der Vollständigkeit
der HTML-Referenz von ZE-WebLab.

WHATWG ist die maßgebliche Primärquelle.

Die Matrix ist ein fachliches Arbeits- und
Qualitätssicherungsartefakt und keine Kopie der WHATWG-Spezifikation.

## Status

Arbeitsstand: begonnen

## Referenzumfang

- HTML-Elemente
- HTML-Attribute
- HTML-Syntax
- Dokumentstruktur und Semantik
- Microdata
- HTML-spezifische APIs
- XML/XHTML, separat
- aktuelle obsolete/non-conforming Features
